# АИС «Парикмахер Онлайн»

Веб-приложение онлайн-записи на стрижку в парикмахерскую (Flask + SQLite).
Реализовано в соответствии с ТЗ (ГОСТ 34.602-89).

## Роли пользователей

| Роль        | Возможности |
|-------------|-------------|
| **Клиент**      | Регистрация/вход, просмотр парикмахерских, услуг и специалистов, запись на услугу, личный кабинет с историей и статусами записей, отмена своих записей |
| **Модератор**   | Привязан к одной парикмахерской. Управляет её услугами и специалистами, принимает/подтверждает/отменяет/завершает записи клиентов своей парикмахерской |
| **Администратор** | Полный доступ ко всем парикмахерским: создание/редактирование парикмахерских, назначение и снятие модераторов, просмотр услуг/специалистов/записей любой парикмахерской |

## Установка и запуск

```bash
python3 -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt

# наполнить базу тестовыми данными (создаст файл barbershop.db заново)
python seed.py

# запустить сервер разработки
python run.py
```

Приложение будет доступно по адресу **http://127.0.0.1:5000**

## Тестовые учётные записи (после запуска seed.py)

- **Администратор:** `admin@barber.local` / `admin123`
- **Модератор** (парикмахерская «Барбершоп «На Тверской»»): `moderator@barber.local` / `moder123`
- **Клиент:** `client@barber.local` / `client123`

Также можно зарегистрировать нового клиента через форму регистрации на сайте.

## Как назначить модератора

1. Войдите как администратор.
2. Откройте **Админ-панель → Пользователи и модераторы**.
3. У нужного пользователя (должен быть предварительно зарегистрирован как клиент) выберите парикмахерскую в выпадающем списке и нажмите **«Назначить»**.
4. Чтобы снять роль — нажмите **«Снять модератора»**.

## Структура проекта

```
barbershop/
├── app/
│   ├── __init__.py        # фабрика приложения, инициализация БД и логина
│   ├── models.py          # модели: User, Salon, Service, Specialist, Booking
│   ├── decorators.py       # декоратор проверки ролей
│   ├── auth.py             # регистрация / вход / выход
│   ├── main.py             # публичная часть: каталог, запись, личный кабинет
│   ├── moderator.py        # кабинет модератора (услуги/специалисты/записи своей парикмахерской)
│   ├── admin.py             # админ-панель (парикмахерские, пользователи, модераторы)
│   ├── templates/           # Jinja2-шаблоны (Bootstrap 5)
│   └── static/css/style.css
├── run.py
├── seed.py                  # наполнение БД тестовыми данными
└── requirements.txt
```

## Технологический стек

- Python 3.10+, Flask 3
- Flask-SQLAlchemy (ORM), SQLite (по умолчанию; легко переключить на PostgreSQL)
- Flask-Login (аутентификация, ролевой доступ)
- Bootstrap 5 (интерфейс)

## Примечания по безопасности

- Пароли хранятся только в виде хэшей (Werkzeug).
- Изоляция данных модератора: все запросы к услугам/специалистам/записям в кабинете модератора фильтруются по `salon_id` его собственной парикмахерской.
- Для промышленной эксплуатации рекомендуется: включить HTTPS, вынести `SECRET_KEY` в переменные окружения, перейти на PostgreSQL, использовать Gunicorn/Nginx.
